Windows 桌面端 Live2D 运行时包提取工具 —— **首个可运行版本**。

自动发现本机安卓模拟器实例，通过 ADB 扫描目标游戏目录，把散落在各处的 Live2D 运行时文件
以 `.model3.json` 为锚点聚合成完整模型包，导出到本地磁盘后直接调用 Cubism Editor 打开。

解决的是「想改游戏里的 Live2D 模型，却要先学会扒包」这件事。

## 下载与运行

下载 **`ShiMo-1.0.0-win-x64.zip`**（112 MB），解压后双击 `拾模.exe`，**无需安装**。
整个文件夹可以直接拷到任意 Windows 10 / 11 64 位机器使用。

> 附件名用 ASCII 是因为 GitHub 会**静默剥掉** release 附件名里的非 ASCII 字符
> （中文会被直接删掉）—— 下载后的文件名因此是 `ShiMo-...`，
> 但解压出来的目录名和程序名都是中文：`拾模-1.0.0-win-x64\拾模.exe`。

- 日志位置：`%APPDATA%\拾模\logs\`
- 使用前提：**模拟器实例需处于运行状态**才能扫描 —— 模拟器系统盘是 vmdk / img 镜像，
  本工具不解析镜像，统一走 ADB
- ⚠️ 未做代码签名，Windows 可能提示「未知发布者」，选「仍要运行」即可

## 功能

| 编号 | 功能 | 说明 |
|---|---|---|
| FR-01 | 模拟器实例发现与连接 | 自动列出本机实例（含多开），标注运行状态与 root 状态；未运行的实例给启动引导而非报错 |
| FR-02 | 扫描范围配置 | 默认覆盖 `/sdcard/Android/data`、`/sdcard/Android/obb`，支持自定义路径；等价路径去重 |
| FR-03 | 资源扫描与进度反馈 | 显示整体百分比**与当前遍历的目录路径 + 实时计数**；可取消，取消后不落盘 |
| FR-04 | 运行时包聚合 | 以 `.model3.json` 为锚点收拢 `.moc3` / 纹理图集 / motions / expressions / physics3 |
| FR-05 | 完整性校验 | 缺 moc3 / 缺纹理 / 无动作 / 无表情分档标注；`.moc3` 版本前移到导出前检测 |
| FR-06 | 结果列表与筛选 | 表格呈现，按完整性与来源分组；底部汇总与勾选严格一致 |
| FR-07 | 导出与另存为 | 原样保持相对路径，文件名不转码 |
| FR-08 | 一键调用 Cubism Editor | 导出完成后直接调起本机 Editor 打开所选模型 |
| FR-09 | 容器资源处理 | 识别 zip 等标准容器并尝试解包；识别不了的文件头**如实说明原因**，不静默跳过 |
| FR-10 | 异常与错误处理 | 每个失败态都给出可执行的下一步，不给静默空表 |

## 已知限制

- **游戏资源常打包进 AssetBundle / `.obb` / 加密容器，明文扫描会扫不到。**
  典型如碧蓝航线：资源在 `Android/data/com.bilibili.azurlane/files/AssetBundles/live2d/`，
  路径可访问但本体是 UnityFS（`.unity3d`），按 `.model3.json` 扩展名一个都扫不到，
  需 UABE / AssetStudio 解析 + 「Unity 动画 → `motion3.json`」格式转换。
  工具对此类资源会如实提示原因。
- `.moc3` **无法反编译回 `.cmo3`**；`.moc3` 版本与 Cubism Editor 支持的 SDK 版本必须匹配。
- 图标为 Electron 默认图标（换图标要给 exe 改 Windows 资源，需 rcedit）。
